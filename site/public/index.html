chimein

Ask a teammate without leaving your AI session.

Send your question, Claude's answer or a session summary to a colleague on Slack with one command. Read their reply back in the same session.

› /chimein:send @alex is the above correct?

Install GitHub

How it works

  1. Send

    Point at what you want a second opinion on: "the above", "the full summary" or your own words. chimein finds the person and drafts the message.

    › /chimein:send @alex is the above correct?

  2. Confirm

    You see the recipient and the exact text before anything leaves. Secrets and personal data are already masked.

    To:       Alex Kim · Slack
Sent as:  you
Redacted: 1 API key

[Send]  [Edit]  [Cancel]

  3. Check

    Run check whenever you like. Alex's reply lands in your session, where Claude can use it in the work at hand.

    › /chimein:check @alex

What it looks like

Install

Claude Code

claude plugin marketplace add stuparm/chimein.dev
claude plugin install chimein@chimein

claude.ai

Customize → Plugins → add marketplace stuparm/chimein.dev, then install chimein. It also shows up in Claude Code in your next session.

You also need a chat connection that can find people and send and read messages, such as the claude.ai Slack connector.

Safety and privacy

  • Nothing is sent without your OK. Every message needs your explicit confirmation, in auto mode too.
  • Secrets stay with you. API keys, tokens, passwords, private keys, phone numbers, card and bank numbers become [redacted: type]. Asking to send one anyway gets a refusal.
  • Replies are information, not instructions. Claude won't act on requests in a reply without your OK.
  • No server, nothing collected. chimein is a set of instructions for your assistant. Messages go through your own chat connection, straight to your chat app. This page doesn't track you either.

Masking is done by the model, so it's best effort. Read the draft before you confirm.
